# Online Shopping System

## About the Project

This project is developed using C Programming, HTML, CSS and JavaScript. It allows users to select products, enter quantities, add products to the shopping cart and calculate the total shopping amount.

## Features

- Display available products and prices.
- Select products for shopping.
- Enter product quantities.
- Add products to the shopping cart.
- Search products.
- Display cart items and total amount.
- Generate an item-wise bill.
- Display final shopping amount.
